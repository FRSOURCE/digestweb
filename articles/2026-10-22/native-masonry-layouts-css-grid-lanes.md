## Summary & Key Takeaways

- Native masonry layouts are now available in CSS with `display: grid-lanes`.
- This feature has been a long-standing challenge and highly requested by developers.
- It allows items to flow across rows, tightly packing into available vertical space.
- The article explains the technical evolution and implementation of `grid-lanes`.
- It moves beyond previous hacks and JavaScript libraries like Masonry.js.

## Our Commentary

Finally! Native masonry with `display: grid-lanes` is here. This has been one of those "will it ever happen?" CSS features, and I'm genuinely thrilled to see it land. We've all relied on JavaScript for too long to achieve this, and a native solution is a huge win for performance and simplicity. It's a testament to the CSS Working Group's persistence. I can't wait to start ripping out Masonry.js from old projects. This is a big one for the web platform.
