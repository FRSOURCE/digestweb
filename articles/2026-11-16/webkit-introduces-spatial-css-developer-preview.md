## Summary & Key Takeaways

- WebKit has released a developer preview of Spatial CSS in Safari on visionOS 27.3.
- The initial focus is on working with 3D objects using the `<model>` element.
- This API aims to enable new immersive web experiences.
- It represents an early look at a proposed standard for spatial web development.

## Our Commentary
