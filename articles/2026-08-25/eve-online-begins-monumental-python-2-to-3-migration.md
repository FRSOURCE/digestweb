## Summary & Key Takeaways

- EVE Online is commencing its migration from Python 2 to Python 3.
- The game has run on Stackless Python since 2003.
- The migration involves 2.4 million lines of code and manual review of 20,000 differences.
- They previously replaced Stackless in their Carbon engine with an open-source scheduler.

## Our Commentary

Wow, EVE Online still running on Stackless Python 2.7? That's a relic! This migration is going to be an absolute beast. 2.4 million lines of code, 20,000 manual reviews... I can only imagine the war stories that will come out of this. It's a stark reminder of the long-term technical debt in large systems. Good luck to them, they'll need it.
