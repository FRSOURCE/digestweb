## Summary & Key Takeaways

- `create-vite` 9.4.0 is now available.
- It includes a new devtools option for project setup.
- Templates for Solid.js now use Solid 2 by default.
- The scaffolding tool adds support for the Vite+ (vp) package manager.
- Dependencies have been updated across the board.

## Our Commentary

A minor update for `create-vite`. Solid 2 support is good to see, keeping the templates current. The `devtools` option is a nice touch for new projects. I'm curious about this "Vite+ (vp) package manager" though; it feels like we're constantly adding new package managers to the ecosystem.
