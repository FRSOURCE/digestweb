## Summary & Key Takeaways

- CodePen has released its new v2 API.
- The API provides full read and write access to Pens, Collections, and Assets.
- It aims to enable developers to build custom integrations and tools.
- The announcement was made via a podcast episode.

## Our Commentary

A full read/write API for CodePen is a nice quality-of-life improvement for its users. It's always good to see platforms open up their data for more creative integrations. It's not a game-changer for the web, but it's a solid enhancement for a popular dev tool.
