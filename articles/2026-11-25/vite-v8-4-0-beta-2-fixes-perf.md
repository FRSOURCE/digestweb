## Summary & Key Takeaways

- Adds plugin names to hook errors for better debugging.
- Fixes server closing on failed start and CSS deduplication issues.
- Improves HTML entry script side effect handling.
- Optimizes source map shifting for preload rewrites.
- Skips build import analysis hooks for unaffected chunks.
- Updates non-major dependencies.

## Our Commentary

This is a solid beta update. We appreciate the focus on stability and developer experience, especially the clearer error messages. It's the kind of iterative improvement that makes a big difference over time. I'm always happy to see performance gains, even small ones.
