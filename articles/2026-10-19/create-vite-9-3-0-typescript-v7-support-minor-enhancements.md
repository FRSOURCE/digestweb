## Summary & Key Takeaways

- `create-vite` now prints its version before scaffolding new projects.
- TypeScript v7 is now used where possible in generated projects.
- Bug fixes include adding router-only options for TanStack Router/Start.
- Dependencies across the project have been updated.
- The internal `cross-spawn` dependency was replaced with `tinyexec`.

## Our Commentary

This is a small but welcome update for `create-vite`. We appreciate the continued refinement of the scaffolding experience. Using TypeScript v7 by default is a good move, keeping new projects on the latest stable. It's the little things that make a difference in developer experience, right?
