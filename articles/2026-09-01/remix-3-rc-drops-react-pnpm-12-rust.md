## Summary & Key Takeaways

- Remix 3 RC is now a full-stack framework that no longer requires React.
- This architectural rewrite allows developers to use Remix with any UI library or none at all.
- pnpm 12 has been rewritten in Rust, promising significant performance improvements.
- TypeScript now supports `import-attribute-aware` ambient modules.
- An impressive 247-byte Minesweeper implementation in JavaScript is analyzed.

## Our Commentary

Remix 3 dropping its React dependency is a monumental shift. We've seen frameworks try to decouple from their UI layers before, but for Remix, this feels like a true re-invention. It opens up so many possibilities for developers who love Remix's conventions but prefer other UI libraries. And pnpm 12 in Rust? Yes, please! Faster package management is always welcome. It's a good day for web tooling.
