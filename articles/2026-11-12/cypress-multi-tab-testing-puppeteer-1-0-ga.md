## Summary & Key Takeaways

- Cypress now supports multi-tab and popup testing with `@cypress/puppeteer 1.0`.
- This release addresses a previous limitation where tests ran in a single tab.
- The package is generally available with a stable API.
- It integrates Puppeteer v24 for enhanced browser control.
- A new guide is available for implementing multi-tab testing.

## Our Commentary

Finally! Multi-tab testing in Cypress has been a pain point for so many teams. This is a huge win for anyone dealing with complex user flows involving new windows or popups. I'm genuinely excited to see how this changes testing strategies. It feels like a missing piece of the puzzle has just clicked into place.
