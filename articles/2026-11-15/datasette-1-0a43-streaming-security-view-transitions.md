## Summary & Key Takeaways

- Streaming support is added for output renderers, including TSV and CSV exports.
- Critical security fixes address potential exposure of private stored queries.
- A new `<datasette-copy-button>` Web Component enhances schema copying.
- CSS multi-page view transitions are implemented, making MPA navigation feel like an SPA.
- Dozens of smaller improvements and bug fixes are included.

## Our Commentary

Simon Willison is always cooking up interesting things with Datasette, and this alpha release is no exception. The multi-page view transitions are a fantastic example of leveraging modern web platform features to enhance the user experience of an MPA. It's a small detail that makes a huge difference in perceived responsiveness. The security fixes are, of course, non-negotiable and always welcome.
