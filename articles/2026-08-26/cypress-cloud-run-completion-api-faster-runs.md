## Summary & Key Takeaways

- The new Run Completion API is available for all Cypress Cloud plans.
- It allows Cypress Cloud runs to finalize immediately after test recording.
- This prevents runs from staying open for new tests, improving efficiency.
- The API is particularly beneficial for runs with multiple groups of tests, such as parallel machines or different browsers.
- It aims to save time by reducing the overall duration of test execution in the cloud.

## Our Commentary

Faster Cypress Cloud runs are always a good thing. The Run Completion API sounds like a solid improvement for anyone running large, parallel test suites. We've definitely felt the pain of runs lingering longer than necessary, so this is a welcome optimization.
