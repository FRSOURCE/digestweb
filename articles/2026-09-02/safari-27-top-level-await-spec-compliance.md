## Summary & Key Takeaways

- WebKit for Safari 27 now fully supports top-level `await`.
- This update brings Safari into full compliance with the JavaScript specification.
- Top-level `await` allows using `await` outside of async functions in modules.
- It simplifies asynchronous module initialization and resource loading.
- This improves consistency and developer experience across modern browsers.

## Our Commentary

Finally, full spec compliance for top-level `await` in Safari 27! This is one of those features that just makes writing modern JavaScript modules so much cleaner. I've been waiting for this kind of consistency across all major browsers. It's a small but mighty win for the web platform.
