## Summary & Key Takeaways

- Deno v2.9.2 includes new features for Deno Desktop.
- It now autodetects React Router framework for desktop apps.
- HMR is enabled for Vite and Nuxt within Deno Desktop.
- New window opacity and transparency APIs are available for desktop.
- Various fixes and minor enhancements are also part of this release.

## Our Commentary

Deno Desktop is quietly getting some really interesting features. HMR for Vite and Nuxt is a big win for developer experience. I'm seeing Deno lean into the desktop space more and more, which is a fascinating direction for a JavaScript runtime.
