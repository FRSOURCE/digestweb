## Summary & Key Takeaways

### Key Additions

- Adds support for the `::highlight` pseudo-element.
- Introduces support for the `@position-try` at-rule.
- Now supports `::search-text` and `:current::search-text` pseudo-classes.
- Collapses `light-dark(x, x)` to `x` for optimization.
- Includes support for `:target-before/after/current` pseudo-classes.
- Adds support for the `alpha()` relative color function.
- Fixes various bugs, including `rrggbbaa` support on older Android versions.

## Our Commentary

Lightning CSS continues its relentless march forward, adding support for a slew of cutting-edge CSS features. We're particularly keen on `@position-try` and the `alpha()` relative color function. It's a good reminder that the CSS spec is always evolving, and tools like this are crucial for adopting new capabilities early. This is a solid update for anyone pushing the boundaries of CSS.
