## Summary & Key Takeaways

- Claude Security now continuously scans repositories as code changes.
- It tracks security findings until they are fixed.
- The system learns from context added by development teams.
- Integration with existing tools is available via an API and MCP.
- This enhanced security offering is in public beta for Claude Enterprise customers.

## Our Commentary

Continuous scanning and fix tracking for enterprise codebases is a solid feature. It's good to see AI providers focusing on the practical integration and lifecycle management aspects of security. The "learning from context" part is particularly interesting; it suggests a more adaptive and less noisy security tool.
