## Summary & Key Takeaways

- Datasette 1.0a37 is a minor alpha release.
- It includes performance optimizations for the permissions system.
- Documentation for permissions has also been improved.
- A cosmetic API change was reverted to avoid breaking plugin test suites.
- This release focuses on stability and compatibility for the upcoming 1.0 version.

## Our Commentary

It's good to see Simon Willison prioritizing stability and plugin compatibility even in alpha releases. Reverting a breaking change, even a cosmetic one, shows a real commitment to the ecosystem. We appreciate that kind of careful stewardship.
