## Summary & Key Takeaways

- WebKit now includes an API for Global Privacy Control (GPC).
- The API is available in iOS, iPadOS, visionOS, and macOS 27.
- GPC is an emerging web standard designed to signal user privacy preferences.
- This implementation allows websites to automatically respect user privacy choices.

## Our Commentary

This is a big win for user privacy. GPC has been a long time coming, and seeing WebKit bake in an API for it is a strong signal. It's one of those features that just _should_ be there. We're always advocating for more user control over data, and this moves the needle.
