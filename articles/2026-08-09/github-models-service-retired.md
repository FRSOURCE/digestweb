## Summary & Key Takeaways

GitHub Models, a unified LLM API and playground, has been retired.
The author discovered the retirement when a GitHub Actions workflow failed.
GitHub did not publicly state the reason for the shutdown.
Speculation points to the high cost of offering free or subsidized tokens for coding agents.
The author migrated their workflow to use the OpenAI API instead.

## Our Commentary

This is a pretty big deal. GitHub getting out of the LLM playground business, especially if it's due to cost, tells us something important about the economics of these services. It makes me wonder if we'll see more consolidation or if the "free tier" for AI will become increasingly rare.
